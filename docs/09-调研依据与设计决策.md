# 调研依据与设计决策

本轮基于已在本机固定检出的 research base 研究，而非仅参考市场介绍。完整提交与检出范围见 [研究来源](research-sources.json)。上游不作为运行依赖，不执行其安装脚本，不复制其模型渠道或私有正文存储。

| 决策 | 依据与取舍 |
| --- | --- |
| 外部 Agent 协作 | 上游的生成、编排与分析转交作者选用的 Agent，本包只保留专业结构与确定性动作 |
| 公开宿主能力 | 正文、候选、设定、证据和CAS复用Core，不在插件保存第二套作品 |
| 专业数据 | 依据清晰、范围固定、可独立升级；布局与候选状态不得变成正式作品事实 |
| 许可 | 参考项目见来源清单；本包独立实现，SDK与实际打包依赖随制品附许可 |

参考项目：LiPu-jpg/Openwrite, KurohaneKaoruko/DSH-Creator。市场收录不代表兼容性、质量或授权已经核验。


审校研究采用连贯逻辑、角色关系、情节承诺、节奏场景、文风表达、设定资料六域；保留未检查与无法判断。标点属于可配置建议，不能阻断正文保存，不能声称检测AI来源。
