# 界面与交互设计

独立工作面使用紧凑工具栏与返回，主体为可筛选问题列表和原文／问题详情。当前小说、报告范围、固定版本和未检查状态持续可见；默认不展示大面积分数仪表盘。

顶部可切换“问题”“覆盖”“本地检查”“历史”。问题按领域、严重度及处理状态筛选；点击问题展示原文依据和修改候选，跨章依据可以分别跳转。作者能阅读未标记位置和完整来源，不局限于Agent摘要。

确定性规则与Agent结论分开标记。覆盖使用已检查来源和未检查清单，不能把检查进度伪装成创作质量。忽略有原因且可撤销；复核和候选状态独立，不能用绿色标签暗示正文已采用。

错误、原文已变、冲突和unknown在当前对象就地显示并保留恢复引用。空状态的AI交接携带本报告范围和目标；不要求用户重新填写对话已有信息。

外观遵循宿主hetu-ui-style、共享Radix语义色和轻透连续背景；正文保持稳定纸面。浅暗、窄窗和键盘完整验证，问题列表与详情可在窄窗纵向切换而不丢当前筛选。
