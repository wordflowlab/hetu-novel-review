# 开发发布与上架

专业规则使用普通TypeScript，React展示问题与来源，受管Node通过公开SDK复用Core。运行包包含完整前后端、Schema、Skill、CAPABILITIES与实际依赖许可，不在安装时执行构建。

发布前完成类型检查、规则及应用单元、真实CLI/MCP、同连接Skill、作者工作面和连续小说旅程；框架版本、规则选择与实际覆盖须进入报告。上游的分数、节点数和测试声明不作为河图门槛。

固定源码提交与精确版本后发布GitHub运行制品，记录归档及包摘要，重新下载校验。插件中心条目绑定精确源码、制品、许可、使用文档与真实验收范围；上线后核对中英文页面及安装卸载使用。

更新不替换旧版字节；报告解释当时框架。升级框架或Schema时保留旧报告语义，显式迁移；撤回目录或卸载插件不删除作品和问题历史。宿主缺口必须在宿主层补齐并同步公共合同及回归。


## 开发者验收环境

先在河图源码仓按其开发入口构建桌面与CLI/MCP，再构建本插件。普通安装使用固定运行包，不需要这些开发工具。

| 参数 | 测试用途 |
| --- | --- |
| HETU_SOURCE | 河图源码checkout绝对目录，用于SDK测试依赖解析和开发桌面；默认相邻limecloud/hetu |
| HETU_TEST_PACKAGE | 已解压运行包的绝对目录；默认dist |
| HETU_TEST_BIN | 确切CLI/MCP/App Server二进制目录；默认宿主target/debug |
| HETU_PACKAGED_APP | 正式安装应用的可执行文件绝对路径；设置后还须明确HETU_TEST_BIN |

测试在隔离profile、插件状态和新作品中运行，不读取作者小说。真实请求和回执保留在隔离目录，公开证据只复制脱敏结果。SDK来源摘要不符、Schema或生成资源错误应修正来源后重建，不能跳过校验。
