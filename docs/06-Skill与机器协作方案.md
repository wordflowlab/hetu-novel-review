# Skill 与机器协作方案

包内 `hetu-novel-review` Skill 按“单章／跨章／整书批次／问题返工／新版复核”路由。入口通过河图稳定发现与skills.read读取，动作参数以本次Schema为准，不要求同名Codex插件或新工具名。

先读当前作品和报告，明确目标、固定来源、实际可读范围与未完成项。适用的确定性检查先运行；外部Agent再按所选域阅读和推理，将问题写成“哪里、依据、影响、建议”的可反驳结论。原文不足以判断时记录inconclusive，不编造引文。

六域是检查维度，不要求开六个Agent或调用六次模型。检查范围与模型上下文相称，保留跨章依赖；不把全书一次性输入作为强制方法，也不以章节摘要证明读过全部正文。

修改候选、作者公开意见及采纳复用宿主任务。再次检查前读取真实新修订，按旧问题和新依据复核；未采用的候选不得替换正式事实。插件无正文写入或自动定稿动作。

未知结果沿原操作回读，冲突保留输入；卸载、停用或包升级后重新发现。完整验收通过当前Codex会话完成问题→候选→意见→复核，GUI只验证作者可视化，不补机器能力缺口。
